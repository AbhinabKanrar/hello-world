How to read this report

Choose the right denominator

Completed responses include don't-know and refused selections. Valid responses exclude them. Technical failures are not answers. The two percentages coincide here because nonresponse is zero.

Separate pipeline quality from model behaviour

These are independent, synthetic, forced-choice responses—not measured human demand. A consistent report can still have an unrealistic distribution. Compare another model using the same instrument, seed, and sample size before changing the prompt.
